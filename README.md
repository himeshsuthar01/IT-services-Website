# IT Services Website

A responsive IT Services website built using HTML and CSS.

## About the Project
This project provides information about IT services through a simple and user-friendly website.

## Technologies Used
- HTML5
- CSS3
- Bootstrap (if used in the project)

## Features
- Home page
- Services page
- Service details page
- Contact page
- Images and styling

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
